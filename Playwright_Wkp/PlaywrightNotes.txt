Playwright
===============
Playwright is end to end automation testing framework for UI, api and mobile web application


Playwright File structure
===========================
1.create spec file
2.inside spec file--> maintain test()  every single test() is 1test case in Pw

How to run playwright testcases
======================================
1.To run all spec files in headless mode
--------------------------
npx playwright test

2.To run all spec files in headed mode
--------------------------
npx playwright test --headed

3.To run any single test case in headed mode
-------------------------------------------------
npx playwright test tests/TestCaseName.spec.ts --headed

4.To run specific test on single browser
------------------------------------------
npx playwright test tests/TestCaseName.spec.ts --headed --project=chromium



BrowserMethods
===================
1.goto("url"):Promise<Response|null>
-------------------------------
Returns the main resource response. In case of multiple redirects,
 the navigation will resolve with the first non-redirect response.

2.title():Promise<string>
-------------------------------
Returns the page's title.

3.url():string
------------------------
Returns the current app url


How to start any browser session Manually
==========================================
chromium object
-------------------
This object can be used to launch or connect to Chromium, returning instances of Browser.

chromium.launch({headless:false,channel:''})

what is launch():Promise<Browser>
==================
Returns the browser instance.

what is channel?
====================
Browser distribution channel.
Use "chromium" to opt in to new headless mode.
Use "chrome", "chrome-beta", "chrome-dev", "chrome-canary", "msedge", "msedge-beta", "msedge-dev", or "msedge-canary" to use branded Google Chrome and Microsoft Edge.

newContext(): Promise<BrowserContext>
=================
Creates a new browser context. It won't share cookies/cache with other browser contexts.

newPage():Promise<Page>
==============
Creates a new page in the browser context.
